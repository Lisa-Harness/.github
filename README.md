# Lisa Harness `.github`

Organization-wide repository for Lisa Harness:

- [`profile/README.md`](profile/README.md) renders as the organization
  profile on <https://github.com/Lisa-Harness>.
- The files under [`.github/`](.github/) are **default community health
  files**: GitHub uses them as fallbacks for every *public* repository in the
  organization that does not define its own (issue templates, pull request
  template, `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`).

The [framework repository](https://github.com/Lisa-Harness/lisa) keeps its
own health files, which take precedence for that repository.
